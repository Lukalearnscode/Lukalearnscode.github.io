Agent Orchestration

Claude and Codex run against each other unattended: one writes, the other is allowed to reject it, and a verifier neither of them can touch decides whether it ships. Wiring them together took an afternoon. This page is the other part — the seven ways a pipeline like this hands you a green light over work that was never done. Not open source.

Localization Pipeline

An AI localization pipeline for EN↔ZH game and creative text: per-project prompt generation, multi-model translation, a three-stage review architecture, and mechanical gates that do not take the model's word for anything. Not open source — the page explains the design itself.

memoQ Tag Transfer

A CLI tool that restores inline formatting tags to translated text, and proves they landed on the right words. The interesting problem was not placing the tags — it was catching the case where every mechanical check passes and the output is still wrong. Open source, MIT.

Huka Run

A playable cel-shaded riverboat prototype set in a Huka Falls-inspired turquoise canyon. This is a personal modification inspired by and adapted from Wave Racer by Vyom-26: I reworked the river, canyon walls, palette, countdown HUD, and one-boat play loop.

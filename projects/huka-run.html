Huka Run

A playable cel-shaded riverboat prototype inspired by the turquoise water and steep volcanic banks around Huka Falls. The scene is procedural, so the river, cliffs, vegetation, foam, wake, and start sounds are all generated in code.

Play Huka Run in the browser →

Reference and changes

This is a personal modification inspired by and adapted from Wave Racer by Vyom-26. I kept the broad boat-and-water direction as a reference, then changed the experience into a single-boat Huka Falls-style river run: turquoise water, taller canyon walls, a blue sky with clouds, a rebuilt shoreline system, and a three-two-one start countdown with sound.

The reference project is credited here deliberately. This page describes my changes; it does not present the underlying inspiration as original work.

Controls

  • Throttle: W / ↑
  • Brake / reverse: S / ↓
  • Steer: A, D / ←, →
  • Powerslide: hold Shift / Space, then release for a boost
  • Reset: R
  • Camera: C

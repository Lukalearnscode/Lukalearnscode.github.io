Huka Run

一个能直接在浏览器里玩的卡通渲染快艇原型，灵感来自 Huka 瀑布一带 绿松石色的河水和陡峭的火山岩岸。整个场景不是手工摆出来的，而是代码 现场算出来的：河道、岩壁、植被、浪花、尾流，连起步的音效都是。

在浏览器里玩 Huka Run →

参考与修改

这是一个个人修改项目，参考并改编自 Vyom-26 的 Wave Racer。 我保留了「船与水」这个大方向，把玩法改成了单艇的 Huka 瀑布风格河道竞速： 绿松石色的水面，更高的峡谷岩壁，带云的蓝天，重建的岸线系统，还有带音效的 三二一起步倒计时。

参考项目特意在这里署名：这一页写的是我改了什么，不会把别人的底子 说成自己的原创。

操作

  • 油门：W / ↑
  • 刹车 / 倒退：S / ↓
  • 转向：A、D / ←、→
  • 漂移：按住 Shift / Space，松开获得一段加速
  • 重置：R
  • 视角：C
